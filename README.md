# WorkoutLog

**WorkoutLog** — мобильное приложение-дневник для силовых тренировок.
Приложение помогает пользователю создавать упражнения, отслеживать подходы, сохранять рабочие веса и получать рекомендацию по прогрессии веса на следующую тренировку.

Проект разработан на **Flutter** с использованием **Firebase Authentication** и **Cloud Firestore**.

---

## Описание проекта

WorkoutLog создан для пользователей, которые занимаются силовыми тренировками и хотят видеть свой прогресс по упражнениям.

Пользователь может создать упражнение, например:

```text
Жим лёжа
80 кг
3 подхода по 8 повторений
```

После завершения тренировки приложение сохраняет результат и на следующей тренировке предлагает увеличить рабочий вес:

```text
В прошлый раз: 80 кг × 8
Попробуй сегодня: 82.5 кг × 8
```

Таким образом приложение работает не просто как список упражнений, а как персональный дневник прогрессии нагрузки.

---

## Основной функционал

### Авторизация

В приложении реализованы:

* регистрация пользователя;
* вход в аккаунт;
* выход из аккаунта;
* хранение пользователя через Firebase Authentication.

---

### Главный экран тренировки

На главном экране пользователь видит выбранное упражнение, текущий подход и список всех подходов.

Статусы подходов:

* зелёный — подход завершён;
* жёлтый — текущий подход;
* серый — подход ещё не начат.

Также на главном экране есть:

* кнопка отдыха;
* кнопка завершения подхода;
* выбор упражнения;
* добавление нового упражнения;
* умная рекомендация следующего рабочего веса.

---

### Умная рекомендация веса

После завершения всех подходов приложение сохраняет тренировку и рассчитывает следующий рекомендуемый вес.

Пример:

```text
Прошлая тренировка:
Жим лёжа — 80 кг × 8

Следующая рекомендация:
82.5 кг × 8
```

Базовая логика прогрессии:

```text
Если пользователь завершил все подходы:
следующий вес = прошлый вес + 2.5 кг
```

Это помогает постепенно увеличивать нагрузку и отслеживать силовой прогресс.

---

### Таймер отдыха

В приложении есть отдельный экран отдыха.

На нём отображается:

* выбранное упражнение;
* текущий подход;
* таймер отдыха;
* список подходов;
* кнопка завершения отдыха.

---

### Добавление упражнения

Пользователь может добавить новое упражнение и указать:

* название упражнения;
* рабочий вес;
* количество повторений;
* количество подходов.

После добавления упражнение появляется в списке выбора.

---

### Выбор упражнения

Пользователь может выбрать упражнение из библиотеки уже созданных упражнений.

Для каждого упражнения отображается:

* название;
* рабочий вес;
* количество повторений;
* количество подходов.

---

### История тренировок

В разделе истории отображается прогресс по выбранному упражнению.

Экран истории включает:

* название упражнения;
* график изменения рабочего веса;
* текущий рабочий вес;
* рекомендуемый следующий вес;
* количество тренировок;
* прогресс по тренировкам за неделю;
* список последних тренировок;
* следующую цель по весу.

История помогает отслеживать, как меняется рабочий вес с течением времени.

---

### Профиль пользователя

В профиле пользователь может просматривать и редактировать личные данные:

* имя;
* телефон;
* дату рождения;
* цель тренировок;
* текущий вес;
* целевой вес;
* процент жира;
* количество тренировок в неделю.

Также профиль показывает:

* количество сохранённых тренировок;
* цель тренировок;
* текущий вес;
* целевой вес;
* процент жира;
* прогресс тренировок за неделю.

## Firebase

В приложении используется Firebase.

### Firebase Authentication

Используется для:

* регистрации пользователя;
* входа в аккаунт;
* выхода из аккаунта;
* получения email и имени пользователя.

### Cloud Firestore

Используется для хранения:

* профиля пользователя;
* созданных упражнений;
* истории тренировок;
* рабочих весов;
* рекомендаций следующего веса.

Примерная структура базы данных:

```text
users/
└── userId/
    ├── name
    ├── email
    ├── phone
    ├── birthDate
    ├── goal
    ├── currentWeight
    ├── targetWeight
    ├── bodyFat
    ├── weeklyWorkoutsGoal
    │
    ├── exercises/
    │   └── exerciseId/
    │       ├── name
    │       ├── weight
    │       ├── reps
    │       └── sets
    │
    └── workout_logs/
        └── logId/
            ├── exerciseId
            ├── exerciseName
            ├── weight
            ├── reps
            ├── sets
            ├── setsCompleted
            ├── recommendedNextWeight
            └── createdAt
```

## Настройка Firebase

Для корректной работы Firebase нужно:

1. Создать проект в Firebase Console.
2. Подключить Android-приложение.
3. Скачать файл `google-services.json`.
4. Поместить его в папку:

```text
android/app/google-services.json
```

5. Убедиться, что в проекте есть файл:

```text
lib/firebase_options.dart
```

Он создаётся с помощью FlutterFire CLI.
